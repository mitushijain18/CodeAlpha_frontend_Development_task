# 🧮 Calculator Project

## 📌 Overview

This is a simple yet functional **Calculator Application** built to perform basic arithmetic operations. It demonstrates fundamental programming concepts such as user input handling, logic building, and UI design.

---

## 🎯 Objective

The main objectives of this project are:

* Perform basic mathematical operations
* Build a user-friendly interface
* Understand event handling and logic implementation
* Practice frontend development fundamentals

---

## ✨ Features

* ➕ Addition
* ➖ Subtraction
* ✖️ Multiplication
* ➗ Division
* 🧹 Clear/reset functionality
* 📱 Responsive and simple UI design

## 🧠 How It Works

1. User enters numbers
2. Selects an operation (+, -, ×, ÷)
3. System processes the input
4. Displays the result instantly
